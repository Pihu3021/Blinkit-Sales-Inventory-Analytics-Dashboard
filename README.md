3.Short Description
This Power BI dashboard provides comprehensive insights into Blinkit’s sales, outlet performance, item distribution, and customer ratings. It helps analyze sales trends across outlet types, sizes, and locations while enabling data-driven decisions for inventory and retail performance optimization.

4.Purpose
To monitor and analyze sales, inventory distribution, outlet performance, and customer satisfaction metrics in order to improve operational efficiency and business growth.

5.Features
Interactive filter panel for outlet location, size, and item type
KPI cards for:
Total Sales
Average Sales
Number of Items
Average Rating

Sales analysis by:
Outlet Type
Outlet Size
Outlet Location
Fat Content
Item Type
Outlet establishment trend analysis over years
Comparative analysis of sales and item visibility
Dynamic and user-friendly dashboard design

6.Key Highlights & Insights

Tier 3 outlets generated the highest sales contribution
Regular fat products contributed more sales compared to low-fat products
Fruits, snacks, and household items were top-performing categories
Supermarket Type1 achieved the highest total sales and item count
Average customer rating remained consistent across outlet types
Outlet establishment trend showed peak growth around 2018
